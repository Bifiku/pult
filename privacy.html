Политика конфиденциальности

«Пульт» — личная программа, которая работает только на компьютере автора каналов. Действует с 4 ноября 2026 года.

Какие данные получает «Пульт»

Google и YouTube

  • Загрузка видео (youtube.upload) — чтобы загружать ролики автора на его канал YouTube с названием, описанием и временем публикации.
  • Чтение данных канала (youtube.readonly) — только чтобы узнать название подключённого канала и показать автору, какой канал подключён.

Instagram

  • Публикация (instagram_business_content_publish) — чтобы публиковать Reels автора в его профессиональном аккаунте Instagram с описанием и обложкой.
  • Основные данные профиля (instagram_business_basic) — только идентификатор и имя пользователя, чтобы показать автору, какой аккаунт подключён.

Код входа Instagram показывается на странице входа только на экране автора, страница никуда его не отправляет. Автор сам передаёт код своей программе через своего бота в Telegram.

«Пульт» не читает, не меняет и не удаляет другие публикации, сообщения, комментарии, подписчиков, статистику или личные данные аккаунтов.

Где хранятся данные

Ключи доступа, которые выдают Google и Instagram, хранятся только в файле на компьютере автора. У «Пульта» нет сервера: данные не отправляются никуда, кроме самих Google и Instagram при публикации ролика. Чтобы Instagram мог забрать видео, на время публикации «Пульт» открывает одноразовую временную ссылку на этот файл и закрывает её сразу после загрузки.

Кому данные передаются

Никому. Данные не продаются, не передаются третьим лицам, не используются для рекламы и для обучения моделей искусственного интеллекта.

Использование и передача данных, полученных через API Google, соответствует правилам Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).

Как отозвать доступ и удалить данные

Доступ к Google можно отозвать в любой момент на странице «Сторонние приложения и сервисы» аккаунта Google. Доступ к Instagram — в приложении Instagram: «Настройки» → «Разрешения для сайтов» → «Приложения и сайты». После этого «Пульт» больше не сможет публиковать, а сохранённые ключи перестанут работать.

Все данные «Пульта» — это файл с ключами на компьютере автора. Чтобы удалить их полностью, достаточно удалить этот файл. Других копий нет.
